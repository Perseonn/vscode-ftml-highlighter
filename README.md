# FTML Syntax Highlighter
A lightweight Visual Studio Code extension providing syntax highlighting for FTML and Wikidot source files.

# Installation
* Obtain the `ftml-syntax-highlighter-0.1.0.vsix` file.
* Open Visual Studio Code.
* Go to View ➡️ Extensions (Ctrl+Shift+X).
* Click the "..." menu in the Extensions panel.
*  Select Install from VSIX...
*  Select the downloaded .vsix file and install it.

Alternatively, use any other VSIX installation method you prefer.

## Supported file extensions
* `.ftml`
* `.wd`
* `.wikidot`
* `.wj`
* `.wikijump`

## Development
Open this repository in Visual Studio Code and press `F5` to launch the Extension Development Host.
